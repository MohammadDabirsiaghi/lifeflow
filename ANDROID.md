# Android build

The Android app wraps the static site generated by Eleventy into `docs/`.

## Build locally

Requirements: Node.js 22+, pnpm 11, and Android Studio with Android SDK installed.

```sh
pnpm install --frozen-lockfile
pnpm run cap:sync
```

Run the project's Eleventy build before syncing whenever `docs/` needs to be regenerated. Commit the resulting `docs/` output so GitHub Actions can package that version.

Open the generated `android/` project in Android Studio to run it on a device or emulator. To build a debug APK from a terminal, run `./gradlew assembleDebug` from `android/` (on Windows, use `gradlew.bat assembleDebug`). The APK is written to `android/app/build/outputs/apk/debug/app-debug.apk`.

## GitHub Actions

The **Build Android APK** workflow runs on every push and can also be started from the Actions tab with **Run workflow**. Download `lifeflow-debug-apk` from the completed run's artifacts.

The workflow creates an unsigned debug APK for testing. A signed release build requires a release keystore and GitHub Actions secrets, which are not configured here.
